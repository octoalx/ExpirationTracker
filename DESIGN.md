# ExpiTrack design system

## Direction

Selected by the owner: merged light graphite/blue concept, a precise working instrument for building supplies. No dark theme, ornamental backgrounds or photographs in the primary inventory list.

## Foundations

- White and mineral gray surfaces, graphite text, restrained blue primary actions.
- Refined sans-serif typography with tabular dates; names and expiration dates lead, barcode and quantity follow.
- Fine separators, 10–12 px control corners, no nested cards or decorative elevation.
- Amber and red communicate urgency with text, using configured thresholds.
- Mobile uses compact records with progressive disclosure; desktop retains a table and bulk operations.

## Interaction

- Scan is visible before scrolling. Known barcodes show exact inventory matches; absent barcodes open registration.
- Date-method changes reveal only necessary fields; a calculated expiry is visible before saving.
- Press feedback and focus rings are immediate; transitions last approximately 160–220 ms.
- Scan and save may provide optional vibration, always accompanied by visible feedback.
- Reduced-motion preference disables decorative movement and vibration.
- Mobile focused panels respect safe areas and remain scrollable with the keyboard open.

## Verification

Image-generated references guide composition. Runtime screenshots, interaction checks and independent review establish implementation quality; a generated image is not runtime evidence.

## App-wide refinement (2026-10-02)

Manrope brand and page titles use weight 800, record names 700, section titles 700. Warm amber markers use #e7a52b, labels #8a520e, pale surfaces #fff7e6 and borders #f0d49a. Urgency and record state remain separate: active blue, archive slate, defect red. Authentication, settings, charts and admin controls share restrained blue actions and opaque white panels. Mobile settings tabs retain their text labels.
