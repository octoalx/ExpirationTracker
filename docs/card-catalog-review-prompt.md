# Инструкция для Windsurf: ревью картотеки товаров в Dashboard

## Контекст
Проанализировать текущую реализацию картотеки товаров в dashboard и предложить объективно лучшее решение: оставить как есть или заменить готовым компонентом (AG Grid, MUI X Data Grid, TanStack Table).

## Алгоритм действий Windsurf

1. Найти файлы с реализацией списка/карточек товаров в dashboard
2. Оценить текущий вариант по критериям:
   - Информационная плотность (1-5)
   - Удобство массовых операций (1-5)
   - Быстрота поиска нужного товара (1-5)
   - Эргономика на 100+ товаров (1-5)
   - Консистентность с UI дашборда (1-5)
   - Трудоёмкость доработок (1-5)

3. Сравнить с альтернативами:
   - AG Grid: нужны сложные фильтры + группировка + >500 товаров
   - MUI X Data Grid: уже есть MUI + нужно inline-редактирование
   - TanStack Table: нужен полный контроль + команда готова писать обёртки
