## Общее для всех трёх

- **Данные примера.** Товары — строймаг (герметик, грунтовка, клей, краска, шпаклёвка, пена, затирка). Даты считаются от «сегодня» = 13.11.2026. Пороги: «Срочно» ≤ 3 дн., «Внимание» ≤ 7 дн. (умолчания из `schema.prisma`; реальные берутся из настроек отдела). Штрихкоды — 13 цифр с верной контрольной цифрой, но **сгенерированы**, настоящим товарам не принадлежат. «Анна Петрова» — выдуманное имя. «Всего 128», «Активные 119 / Архив 6 / Брак 3» — макетные числа; на экране 25 строк из 128 по сроку.
- **Одна шкала срочности** (малое пятно, не заливка строки): «Просрочен» — красная таблетка с белым текстом → «Срочно · N дн.» — красный текст на бледно-красном → «Внимание · N дн.» — янтарный текст на бледно-янтарном → «Осталось N дн.» — графит без цвета. Для записей «Архив» и «Брак» срочность не показывается (по правилу «архив и брак исключены из проверки сроков»). Дата везде табличными цифрами, крупнее названия или равна ему.
- **Тексты** взяты из `INVENTORY.md` дословно (сверка скриптом по всем текстам макетов). Новых строк интерфейса всего две: «Экспорт в Excel» (вместо «Печать») и подписи порогов «до 3 дн.» / «до 7 дн.» у групп B. Остальное — подстановки в шаблоны инвентаря («Осталось N дн.», «Выбрано: N», «Годен до: дд.мм.гггг», «Просрочено на N дн.», «Просрочено: N · Срочно: N», «Активные: N · Архив: N · Брак: N») и подписи листа компонентов, которые не часть интерфейса.
- **Что не нарисовано**: остальные 7 экранов, окна «Добавить товар», «Сканировать товар», «Импорт из Excel» (кнопки на месте, окна — следующий этап). «Добавить» на телефоне вынесено в шапку, профиль — во вкладку «Настройки».
- **Термины.** FEFO — «первым истекает, первым продаётся»: список, отсортированный по сроку. Токены — именованные значения цвета и размера в `:root`, из которых потом собирается стиль приложения. Контраст — отношение яркости текста и фона по формуле WCAG 2.x: обычный текст нужен ≥ 4.5:1, элементы без текста (рамки, полосы) ≥ 3:1.
- **Контраст** посчитан скриптом из значений в `:root` самих файлов (не на глаз и не по скриншоту). Тёмной темы нет.

## Рекомендация

**Лучшее по совокупности — C «Пульт», с одним заимствованием из B.** Почему: C сохраняет всё, что требует контракт проекта (таблица и массовые действия на десктопе, боковая колонка, как сейчас), и сразу решает две заметные проблемы — четыре места с числами и срочное, смешанное со всем остальным: сводка становится фильтром, FEFO — первой группой. Людям не придётся переучиваться, как в A (новый шрифт, верхняя навигация) или B (таблицы нет). Но на телефоне — главном устройстве — B читается лучше всех: крупная дата и группы «Сегодня / Срочно / Внимание» — это ровно то, что нужно видеть на ходу. Поэтому я бы взял десктоп C, а телефонный список сделал по B (группы по срокам вместо плоского списка, дата 22 px). A — хороший «плотный режим» таблицы для тех, кто сидит за компьютером, его можно добавить позже переключателем плотности.

Это моё мнение, оценку по рубрике `DESIGN-RUBRIC.md` и независимое ревью я не запускал: задача была сделать макеты, а рубрика относится к готовым страницам.
