# ExpiTrack Style Guide

## Use everywhere:
- Tailwind CSS (NOT React Spectrum)
- shadcn/ui components
- lucide-react icons
- cn() for classes

## Colors:
- Primary: emerald-600 (buttons, accents)
- Background: gradient from-slate-50 via-white to-emerald-50/30
- Cards: bg-white/80 backdrop-blur-sm rounded-2xl

## Components:
- Buttons: Button from shadcn
- Inputs: Input + Label from shadcn
- Modals: Dialog from shadcn
- Tables: Table from shadcn

## Pages:
- /auth/* - Glassmorphism centered card
- /dashboard - Table + FAB button
- /settings - Tabs + forms with cards
